# ChatApp
A simple internal chat application for company employees, built with Python, socket, and tkinter. It supports account registration, login, and one-on-one / group chat rooms, communicating over a custom text-based protocol on top of TCP.

#How to run:
1. Download zip file or clone the project from GitHub
2. Start the server: python server.py --port 5000
3. Start a client: python login_gui.py
4. Multiple clients can run simultaneously to simulate multiple employees.
